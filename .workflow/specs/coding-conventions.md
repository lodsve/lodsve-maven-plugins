### Java 插件编码约定

沿用 .editorconfig：UTF-8、LF、4 空格、一般行宽 120（Markdown 500）。类 PascalCase、方法/字段 camelCase、常量 UPPER_SNAKE_CASE；包名 com.lodsve.maven.plugin。保留 Apache 许可证头与现有导入分组。

证据：`.editorconfig`。
